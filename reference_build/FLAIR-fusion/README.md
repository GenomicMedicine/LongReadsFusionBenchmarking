# FLAIR-fusion Reference Notes
FLAIR-fusion relies heavily on transcript quantification in addition to structural genes:
1. `GRCh38.primary_assembly.genome.fa`
2. `gencode.v44.primary_assembly.annotation.gtf`
3. `gencode.v44.transcripts.fa` 

These files are all handled uniformly by `bash ../common/build_reference.sh`. Please run that script first.
